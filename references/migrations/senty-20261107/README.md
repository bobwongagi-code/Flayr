## 离线验证

从 Flayr 根目录运行：

```bash
python -m unittest discover -s tests -p test_senty_content_migration.py -v
```

21 项测试只使用合成资料和公开方法，不读取内部素材或真实密钥。引用扫描集成用例需要 ripgrep，缺少时明确跳过；归档及结构测试不依赖它。

本机保留完整归档时可运行：

```bash
python references/migrations/senty-20261107/verify_content_transfer.py
```

检查全部封存路径/哈希及关键 JSON 结构；源仍存在时检查源新增、缺失和变化；源已不存在时只核归档，不谎称核过原件。也在无源副本内验证可读、损坏、缺失与断链。清单不由验证工具自动重封。公开检出缺少内部归档时不能执行这条原件检查，应运行上面的合成测试。

`audit_external_references.py` 是本机按需扫描器，检查常见凭据文件及 JSON 键/值，保留重复成员与 Unicode 转义，媒体格式误报按匹配位置单独处理。结果仅记录位置和类别，不输出凭据值；运行会读本机已配置的密钥参考作内存比对，结果不入库。扫描不承诺覆盖未知凭据格式或任意二进制，也不检查线上项目状态。
