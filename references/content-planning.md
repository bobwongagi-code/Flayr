# 商品理解到内容方向：Zero / A / B / C 共用方法

本方法吸收 Senty 的内容策划资产，与 Flayr 已有商品地基、结构职责和当前冻结方案去重结合。不新增方向、生产字段、自动接口或评分。公开范围见 [迁移说明](migrations/senty-20261107/README.md)，原始任务和媒体仅留本地，历史方法不作为现行指令。

## 1. 先判断，再选画面

按“商品和购买问题 → 购买理由 → 内容任务 → 表达与证据 → 具体拍法”推进。复用已核输入，不要求逐项填表；缺什么只有在影响方向时才核。结果写进现有 C、任务备注或稿件，不为流程另起平行简报。

| 要回答的问题 | 复用底料 | 判断与边界 |
| --- | --- | --- |
| 谁在什么情况下需要它？ | 地基的 usage_context、已知购买疑问、评论/业务反馈 | 区分实际反馈与分析提议，不从商品标签或本地地名编出已验证需求 |
| 买家想得到什么？ | consumer_outcome、用途、商品特点 | 需求是具体麻烦或期待，不是把功能改写成抽象口号 |
| 为什么选择这款？ | 已有功能、限制、替代做法、参考表达 | 产品角色要与理由对应；商家自述、参考说法不自动成为已核事实 |
| 为什么相信、还犹豫什么？ | observable_signal、proof_condition、真实使用/结果、主动信任材料 | 明确哪段画面/资料能回答哪项疑问，不能用动作、反应或字幕冒充效果 |
| 下一步该讲哪件事？ | 本次作者任务、已有视频和可用资源 | 写一句能指导镜头取舍的主线，不先挑最清楚的截图再倒推主要问题 |

可以内部记录功能/情绪动机、理解成本、购买风险、结果出现条件、自用/送礼等判断，但仅在影响内容取舍时写。不是每款都填满一套产品性格，也不单凭价格断言冲动购买。

一句主线的写法：“对有某个需求的人，在某个情境里，让其看懂本品怎样带来某项价值，以及相信它需要看到什么。”它是本方向的内容任务，不是固定功效承诺。

## 2. 卖点取舍：成立性与表达方式分开

候选可以来自商品资料、参考、已确认业务反馈或推导，分别留来源、日期/片段及核准状态。不同来源回答不同问题，不排成一列通用的强弱分数。

| 处置 | 含义 |
| --- | --- |
| 保留 | 本次用途有相应依据，可继续纳入策划；不自动代表性能、当地需求或销量已验证 |
| 不用于本次 | 不支持本次商品/场景、材料矛盾，或与本次任务不相关；说明具体原因，不据此否认商品全部价值 |
| 待核 | 缺影响本次表达的事实或条件；保留问题，不伪装成可执行成稿 |

再决定怎样表达：实际使用、可见结果、解释、主动作出的口碑/认证表达、字幕等都可以有价值。**先看购买决策的重要性与依据，再看怎样拍清楚；不能按视觉分数压掉重要但难拍的理由。** 不容易视觉化不等于卖点不成立，容易拍也不等于首要购买理由。

产品资料证明“资料写了什么”；视频证明“这段表达了什么”；人工确认需保留确认范围；模型或分析者推导只作提议。高 GMV 不单独证明拍法有效，沿用曝光/投流/价格/时间等可比性核对。

## 3. 从 C 派生 B，不机械套两条线路

沿现有方向链写：谁遇到什么问题 → 商品价值 → 具体用法/结果如何让人看懂 → 参考 → 拍摄条件 → 证据状态 → 适用限制。

“生活情境带入”和“直接演示价值”只是两种表达方法，可选其一、合用或不用。不固定输出两套或三套，也不把早高峰、前三秒、前后对比设为所有商品的唯一模板。方向数量由成立的购买理由和可行条件决定。

区分购买理由不同、同理由换情境、同理由换拍摄条件；换布景不是独立方向。方向优先级说明依据及取舍，不按卖点、场景、动作或镜头数量排名。

一个可用方向应让作者知道：讲什么、需要什么、关键画面是什么。把分析压到后台，作者阅读层按已定方向卡/拍摄卡呈现，不新增长篇成交报告。

### 场景必须服务购买问题

先确定触发问题和商品回应，再选择人物、地点、动作、道具及必要的时间关系。标签用于检索和检查用途范围，不替代商品理解；资源只依据本人视频、业务确认或直接询问，不从画像推断作者家中有车、宠物或孩子。

本地化不是强行写吉隆坡、mamak 或曼谷。普通桌面、厨房也可能最适合本次表达；只增加真正影响拍法的生活细节。无合适依据时使用通用提议，不冒充本地常见手法。候选见 [本地场景资料](local-context-candidates.md)，不自动应用或放行。

其中场景库已由用户确认曾经马来西亚本地人审核，应作为已有内容资产复用，不一律退回“未经核准”。新增商品/情境仍检查适用性；不会因原审核信息未逐条附签名就要求整库重审。

### 与 C 简报字段的对照

| 原 Senty 内容字段/逻辑 | 本次吸收位置 | 不继承什么 |
| --- | --- | --- |
| productJudgment / purchaseMechanism | C 的购买问题、商品角色、相信与购买条件 | 不由关键词自动判购买性格或成交因果 |
| productProposition / productThesis | 每个方向的一句话内容主线及购买理由 | 不把整款商品固定成唯一不可改的命题 |
| differentiatedSellingPoints | 卖点保留、不用于本次、待核及来源/理由 | 不把易拍排在重要性前，不继承固定视觉分数 |
| localizedScenes / frameworks | C 的方向链、B 的资源条件和具体镜头 | 不强制本地地名或两个线路模板 |
| proofPlan / objectionHandling / cta | 已有证明条件、相关购买疑问及行动 | 不统一追加专业资料/价格门槛，不编交易条件 |
| contentPortfolio / validationPlan | B 持续创作的分工和采用观察 | 不自动扩试，不沿用成交因果和旧实验门槛 |
| evidenceLevels / review | 对齐现行来源标注与人工定稿 | 不把产品自述升级成效果实证，不迁质量分自动放行 |

12 步原判断链完整保存在 [原提示词](migrations/senty-20261107/content-framework-original.md)，作为 C/B 候选来源而非另一个执行入口；按本文件去重吸收其商品、需求、表达与复核职责，不重新引入冲突的排序和固定产物数量。

### 一款多条内容

同一商品可以分别解释使用方法、结果、适配疑问、不同情境或购买条件；每条有清楚的内容任务，不强迫单条承载全部信息。它属于 B 的持续创作策划，不另设新方向，也不承诺这套组合能带来销量。

最大异议只处理有依据且本条相关的疑问，不能给所有产品统一添加价格、退款或专业参数门槛。消费者 CTA 只用本次已确认的入口与交易条件，不编优惠、稀缺或收益。

## 4. A 与 Zero 怎样复用

| 使用处 | 做什么 | 不能做什么 |
| --- | --- | --- |
| A 学习/交稿反馈 | 对照实际商品、已发材料和整片，检查购买问题提出后是否有产品回应、正确使用、可见结果和必要信任支撑，找主要断点 | 不只数动作，不强制拍齐 S1–S6，不由抽帧未见推“没有”，不改 GT/标尺或恢复自动定档 |
| Zero 内容观察 | 指出本人某段具体做法帮助买家理解什么，并核对应原片时间 | 不从标题编夸赞，不把分析推论写成真实观众反应，不强制首条就给改法 |
| Zero 素材重组 | 先说明重组后多表达哪个购买理由，再列各片段原意、入出点、连接逻辑，随样片简短说明改动 | 不把不同条件剪成同一次测试，不弥补原素材不存在的使用/结果，不把策划方法当剪辑能力已完成 |

## 5. 原有交付环节内复核

执行者用下面问题检查本次现有稿，不新增用户填表或评分：

1. 主建议对应哪个购买问题？为何比局部构图更重要？有没有已有材料与该判断相反？
2. 使用对象、部位、条件和结果是否与本品相符？实际使用、普通状态和产品效果有没有混写？
3. 每项事实能否回到当前来源？来源主张、已观察、人工确认与创意提议有没有混淆？
4. 方向差异是真实购买理由或条件差异，还是只改布景/词句？重要但暂缺证据的方向有没有被悄悄删掉？
5. 作者能否复述需要什么、拍什么、关键镜头是什么？内部依据和作者正文是否分开？

沿用 creator-communication.md 的实际作者稿扫描与人工定稿；扫描、字段完整或历史测试通过均不证明建议准确、本地自然或已获外发批准。本次只吸收内容资产，不改自动生成器。
