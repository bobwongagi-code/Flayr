# S3 职责修正与七组复核收尾

日期：2026-09-19。依据：用户确认的职责修正和本批已有人工说明。本文不是准确率提升报告，不据此调整历史分数。

## 已批准的职责

S3 是“功能与使用表达”。具体功能/用法讲解与真实使用演示均可参与。讲解须说明功能与需求、适用对象/场景、条件或步骤的具体联系，品名、泛泛好用和裸功效声称不足以成立。

- 双方口播，比较具体性、相关性、清晰度和组织；相当可以是 `none`。
- 双方都没有合格讲解或使用，才是不涉及；证据不足保留未知。
- 不以口播字数、卖点数量、场景数量或演示形式自动决定档位。
- 建议先改善已有拍法，再可选说明增加真实使用镜头的收益。不要求所有视频补齐六阶段，也不以销量反推内容更好。
- S4 的效果证明与 S5 的独立信任来源不变。本人牙白不是独立背书，不能恢复用户已撤回的 S5 `none`。

## 实现边界

阶段证据合同升至 v7。S3 合格路径为完整的实际使用信号组，或可引用的 `functional_explanation` 信号。前者仍需画面，后者需口播/字幕；二者不互相伪装。

`usage_evidence_state` 继续仅表示实际使用。新增 `functional_explanation_met`，使具体讲解可以与 `usage_evidence_state=none` 同时成立。解析、引用校验、事实一致性检查和比较约束同步更新。讲解不能伪造视觉布尔值，也不能在下游被丢弃为明确缺失。

原来只适用于视觉动作的下限，不再直接给包含具体讲解的比较定档；保留模型比较结果，不另造一套讲解评分表。纯讲解没有视觉执行分；边讲边演示仍保留实际使用的诊断信息。未知的绝对讲解质量不自动记为弱、满分或双方未达到，且不影响已得到的相对比较。Phase C 仍只补事实，不新增定档或建议权限。

## 独立工程修复

Niacinamide 的原始 S4 响应包含双方字段。故障发生在本地第二次投影：`absent + unknown` 已被阻断，第二次投影却只补出 absent 一侧的字段，触发“双侧字段不完整”。

修复让重复投影保持一致：阻断状态不凭空新增单侧字段；双侧明确缺失稳定生成双方缺失字段；真正已通过交接的输出仍必须提供完整字段。没有放宽证据门槛或跳过验证。原运行继续保留 `FAILED`，修复不等于旧结果已成功完成。
