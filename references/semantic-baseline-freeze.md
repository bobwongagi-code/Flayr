# Flayr 离线语义基线冻结协议

本协议冻结于 2026-08-15。机器可读合同是
[`semantic-baseline-freeze.json`](semantic-baseline-freeze.json)，本文件只解释执行方式。

## 冻结目标

这轮只回答一件事：在生产行为基线 `697ad01351fc18b8aba32e00c047ec21708b44db`、
`qwen3-vl-plus` 视觉观察和 `qwen3.7-plus` 判断路由下，现有可用人工 GT 能证明的 Stage1
事实召回、资格交接和 S1-S6 判断质量分别是多少。

它不是 fresh blind promotion。所有结果先作为离线语义基线和根因诊断，`promotion_eligible=false`。
技术门禁通过不能替代语义验收通过。

## 执行顺序

1. 先盘点现有 GT 和身份兼容的历史 artifact，不调用模型。
   只有 `_SUCCESS.json` 可校验、模型路由一致、分析 schema 与管线版本一致，且代码身份属于冻结行为
   提交或当前已通过冻结校验的源码时，artifact 才可进入评分。身份缺失或不兼容的产物单列清单。
2. 旧 16 组通过 `legacy-gt-migration-inventory.json` 显式保留歧义。旧 `small` 不自动解释为
   当前 `small` 或 `none`；无法确认的格子不进入分母。
3. 先离线计算 Stage1 关键事实召回、资格保存、Stage2 使用、relation、gap、完成率和失败类型。
4. 盘点完成后，只有缺少必要且当前身份兼容 artifact 的样本允许定向调用。成功调用立即冻结，
   不因其他样本失败而重跑。调用前必须是干净工作树、冻结校验通过，并显式列出缺失样本。
5. 不达标时只选择贡献最大的一个根因，进入新的、版本化的单变量验证周期。

本轮权威输入已经冻结为 `semantic-baseline-gt.json` 和 `semantic-baseline-manifest.json`。它包含 7 组
已有 `new12 human_initial` 与 5 组有明确人工理由的旧样本，共 12 组、59 个可评分 gap/relation 格、
9 个 `not_applicable` 格、2 个 `uncertain` 格、2 个缺失格和 13 条人工关键事实。未进入该快照的旧
16 组歧义格仍保留在迁移清单中，但不再阻塞这次选定 cohort，也不能被工程侧猜测补齐。

## 冻结门槛

- 至少 12 组可评分样本；
- 至少 12 个 relation 格；
- 至少 12 条人工关键事实；
- gap 与 relation 准确率均至少 80%；
- Stage1 关键事实召回率至少 90%；
- gap 预测覆盖率 100%；
- 两档错误、方向反转和 `NA`/可比较状态误判均为 0。

零严重错误是全自动生产晋级门槛，不是对永久能力边界的一次性判决。出现一个严重错误时，本轮不得
晋级，但必须先按冻结规则归因。不能在同一轮里删样本、改阈值或改 Prompt 后继续累计分数。

## 冻结期间允许修改的边界

| 问题 | 处理 |
|---|---|
| 网络或供应商瞬时故障 | 记录或技术重试，不修改语义合同 |
| request identity、字段丢失、代码崩溃等确定性工程 bug | 新 commit 修复，重走技术门禁，并开始新的语义周期 |
| Prompt、schema、资格定义、gap 标尺 | 当轮禁止修改，只登记为下一轮候选 |
| GT 或评分器错误 | 停止评分，版本化修正后复算现有输出，不自动重跑模型 |
| 因结果不好而修改样本、阈值或分母 | 禁止 |

## 旧 GT 迁移

旧 16 组没有 `none`，也没有完整方向轴。工程侧只能提出迁移候选，不能替专家补写意图：

- 旧 `small` 默认 `legacy_ambiguous`；疑似迁移到 `none` 的格子必须由专家确认；
- 旧 `medium/large` 只能用于 magnitude-only 诊断，方向没有独立确认前不计算 relation；
- 已明确写出原因的旧 `NA` 可以保留为 documented legacy applicability；
- 其余迁移至少抽查 5 格，覆盖多个阶段和档位；发现一次解释偏差即暂停整批迁移；
- unresolved 格子从语义分母排除，同时在覆盖率报告中显式出现。

## S4 梯度 A/B 的现行解释

严格 A/B 确实完成了 8 次新调用，两臂协议哈希一致，4 个样本的最终 relation 和 gap 输出完全相同。
但实验之后 Frosty 从 `large` 修正为 `medium`，Niumo 和 Pet Chews 从 `none` 修正为 `NA`，因此旧
`2/4` 不能继续作为当前准确率。

可保留的结论只有：在这 4 个 seen 样本和当前传递方式下，人工复核梯度没有改变最终输出，因此
没有观察到局部输出收益。GT 修订使旧绝对准确率失效，但不改变“两臂逐格输出相同”这一观察。
跨样本、跨阶段的一般净收益仍然未知；暂停扩大该路线是因为现有局部证据不足且当前应先完成 GT
迁移与语义基线，不是因为梯度传递已经被普遍证伪。当前不扩展生产 Q schema 或 Resolver。

未来若在稳定 GT 上重启该路线，除最终 `gap_magnitude` 外，必须独立统计 `gap_floor`、`gap_ceiling`
及其区间是否包含 GT。区间正确但最终档位错误，归为区间内校准错误；区间本身排除 GT，归为判断
框架错误。两类错误不得合并成一个 exact-gap 指标。

## 首轮离线盘点结果

2026-08-15 在不调用模型的前提下扫描现有完整 `analysis.json`：

- 共发现 3 份完整历史分析，分别是 2 份 Aavini 和 1 份 kakwan；三者都能对应当前冻结 GT；
- 三份产物都来自旧模型路由、旧代码或旧 schema，不能满足本轮冻结身份；
- 符合本冻结身份的可评分 artifact 为 0，因此本轮没有生成语义准确率，也没有用不兼容产物凑分；
- 离线评估器已经按冻结 cohort 生成精确缺失清单，共 12 组，不再扫描或批量重跑其余旧样本。

当前状态是“12 组 GT 快照已冻结、兼容 artifact 待按缺失清单定向补齐”，不是语义验收通过或失败。
定向调用前必须提交本轮评分器与快照改动，保证工作树干净并重新通过冻结校验；之后一次只跑一个普通
样本，成功产物立即冻结，失败则停止并归因，不连续重试。Aavini 等边界样本不能作为首个调用。
